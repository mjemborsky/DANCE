POTENTIAL NAMES

# D.A.N.C.E.
Dynamics and Active Noise Cancellation Engine

# G.L.A.N.C.E.
Gain Limiter and Active Noise Cancellation Engine

# A.N.C.H.O.R.
Active Noise Cancellation and Headroom Optimizer Rig


SUMMARY

This is a dual-purpose device with a "standby" mode, an "active/on" mode and a switch to toggle between. In standby mode, the device acts as a de-esser/clipper and actively processes signals from a microphone and routes it back to the interface. In active mode, the de-esser still functions but there is an active noise cancellation that will be applied (eliminating certain frequencies based on input from microphone).
